# Sky-Fly

Puedes visualizar el prototipo interactivo aquí: 🔗 https://www.figma.com/proto/8rK5eIFVvtRXetxBzH9Vug/DCU?node-id=86-4257

Caracteristicas principales
* Página de inicio con promociones destacadas.
* Formulario de búsqueda de vuelos con opciones avanzadas (origen, destino, fechas, pasajeros).
* Pantalla de selección de vuelos con filtros por precio, horario y aerolínea.
* Proceso de pago con indicadores de progreso y resumen de reserva.

Tecnologías utilizadas
* Figma
